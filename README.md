# Blinkit Sales Analysis Dashboard

An interactive Power BI dashboard developed to analyze Blinkit's sales performance, customer satisfaction, and inventory distribution using 8,500+ records.

## Project Overview

The objective of this project is to analyze sales and outlet performance, identify key trends, and generate actionable business insights using Power BI.

The dashboard provides a consolidated view of key business metrics and enables analysis across product categories, fat content, outlet types, outlet sizes, locations, and establishment years.

## Dataset

- Records: 8,500+
- Domain: Retail / Quick Commerce
- Tool: Power BI

## Key KPIs

- Total Sales
- Average Sales
- Number of Items
- Average Customer Rating

## Analysis Performed

The dashboard analyzes:

- Sales by Fat Content
- Sales by Item Type
- Sales by Outlet Type
- Sales by Outlet Size
- Sales by Outlet Location
- Sales by Outlet Establishment
- Fat Content by Outlet
- Overall outlet performance using key KPIs

## Key Insights

The dashboard helps identify:

- Product categories contributing significantly to overall sales
- The relationship between outlet characteristics and sales performance
- Sales trends across different outlet locations and sizes
- Differences in performance based on fat content and item type
- Customer rating patterns across outlet and product categories

## Project Outcome

Developed an interactive Power BI dashboard that transforms raw retail sales data into meaningful KPIs and visual insights, supporting data-driven analysis of sales and outlet performance.
